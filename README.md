# GlobalDorm

GlobalDorm is a full-stack accommodation booking platform developed as a university software project.

The application allows users to create an account, sign in, browse available accommodation, make room bookings and manage their reservations through a web-based interface.

## Features

- User registration and login
- Authentication and protected routes
- Room booking functionality
- Reservation management
- View existing reservations
- User profile information
- Frontend and backend separation
- Database-backed user and booking data

## Technologies

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

The project is split into separate frontend and backend applications.

The backend follows a structured approach using:

- Controllers
- Routes
- Models
- Middleware
- Database configuration

The frontend uses reusable components and separate pages for authentication, room booking and reservation management.
